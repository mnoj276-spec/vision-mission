# Vault Glossary & Definitions 📖

- **Deduplication Gates**: The 3-stage check (SHA fingerprint, fuzzy match text, variant titles) used to block scraping duplicates. See [[AI_CONTEXT]].
- **Horizon**: Laravel Horizon provides a beautiful dashboard and code-driven configuration for Redis queues. See [[JOBS_AND_QUEUE]].
- **IndexNow**: A protocol allowing websites to notify search engine hubs (like Bing) instantly about content changes. See [[SEO]].
- **OcrManager**: The global service manager orchestrating multiple text-extraction engines (PaddleOCR, Tesseract, Gemini, etc.). See [[SERVICES]].
- **Pail**: Laravel Pail is a tool used to watch and tail Laravel error logs directly inside the terminal console. See [[LOGGING]].
- **Programmatic SEO**: Automatically generating high-quality detail landing pages for cities, categories, and eligibility criteria. See [[SEO]].
- **Quarantine**: The state of crawled items that fail AI confidence scores (e.g., <85%) waiting for manual admin approval. See [[AI_CONTEXT]].
- **SSRF Defense**: Domain whitelist and IP checks guarding curl requests against Server-Side Request Forgery. See [[SECURITY]].
