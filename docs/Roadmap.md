# Project Roadmap & Milestones 🗺️

This document tracking outlines key upcoming feature milestones.

## Prioritized Pipeline
For specific task details, see [[TODO]].

### 🔴 Immediate (High Priority)
- **Push Notification Subsystem**: Direct browser and device alerts for candidates when a matching job is published.
- **Email Digest Delivery**: Compile weekly preferences digest emails instead of immediate transactional blasts.
- **Ingestion Expansion**: Map and add 20 additional municipal government job portals to scrapers.

### 🟡 Mid-Term (Medium Priority)
- **Candidate Match Engine**: Enhanced user profiles with auto-matching notifications based on caste, age, and qualifications.
- **Admin Dashboard Charts**: Analytics visualizations of views, crawler throughput, and duplicate ratios directly in Filament.
- **PDF Resume Builder**: Expose automated profile exports to candidate dashboard.

### 🔵 Long-Term (Low Priority)
- **Native Mobile Apps**: React Native wrapper around Stateless REST API.
- **Offline PWA Enhancements**: Enable full client-side indexing and bookmark search offline.
- **Regional Languages Support**: Machine translation services for job description schemas into regional languages.
